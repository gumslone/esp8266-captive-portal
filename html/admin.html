Portal settings

Forgot the admin password? The FLASH-button reset (or deleting portal_config.lua) goes back to config.portal_admin_password.

Captive page

Page shown to guests. Any portal_*.html on the device can be chosen; applied live.

Login form

Form shown when login is required. Any login*.html can be chosen; applied live.

Nearby networks

Scans for other Wi-Fi networks (takes a few seconds). Useful to pick a quiet channel.

Edit file

Text files only. In portal pages, {{SSID}} is replaced with the network name. Saved line by line (no restart).

Backup

Settings saved on this page (incl. the admin password) live in portal_config.lua. Download settings to keep a copy. To restore (e.g. after re-flashing): upload the file below as portal_config.lua, then restart.

Upload file

Any file (e.g. .lua, sound.mp3 for the captive page). Overwrites a file with the same name.
